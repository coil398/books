本書の前提

Pi SDK、LangChain、LangGraphは、いずれもAIエージェントを作るために使える。しかし同じ層の製品ではない。本書は機能一覧ではなく、実行時に何を所有し、どの状態を管理し、どの責務を利用者へ残すかで比較する。

到達点
  • 三者の抽象化レベルを分ける
  • 同じ要件の実装差を説明する
  • 要件から一意に選定する
対象
  • LLMアプリ開発者
  • agent基盤設計者
  • framework選定者
前提
  • TypeScript基礎
  • APIとJSON Schema
  • tool calling概要

LangGraph

章構成

00全体像Pi SDK・LangChain・LangGraphを抽象化の層から整理する。01エージェントループの解剖モデル、ツール、状態、停止条件、再試行を分解する。02Pi SDK薄いエージェントハーネスとしての設計と制御面を読む。03LangChainモデル統合、ツール、構造化出力、middlewareを読む。04LangGraph状態グラフ、永続化、中断、長時間実行を読む。05正面比較制御性、抽象化、運用、依存、コストを比較する。06実装パターン同じ業務要件を三方式でどう組み立てるかを見る。07選定と運用要件から一意に選ぶ規則と導入手順を定める。
